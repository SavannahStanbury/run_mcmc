# REACH MCMC Pipeline

This repository contains analysis and simulation scripts for MCMC-based modelling of REACH-like global 21cm signal analyses and foreground modelling.

---

- run_mcmc_best_fit.py
- run_mcmc_reach.py
- run_mcmc_nuisance.py
- run_mcmc_nuisance_reach.py

## Joint likelihood analyses
- run_mcmc_joint_likelihood.py
- run_mcmc_joint_reach.py
- run_mcmc_joint_nuisance.py
- run_mcmc_nuisance_joint_reach.py
